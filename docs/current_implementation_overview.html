메시지 분류 순서도

1

Telethon이 메시지 원문과 채널 정보를 SQLite에 저장합니다.

2

Solana CA만 추출하고 모든 메시지를 LLM으로 분류합니다.

3

CA-only 게시물은 같은 채널의 직전 60초 action context를 검사합니다.

후보 1개: 결합 분석 후보 다수: ambiguous 자체 설명+CA: 독립 분석
4

같은 채널과 같은 CA의 반복 언급은 새 이벤트가 아니라 기존 Call Event에 합쳐집니다.

5

첫 실제 BUY_CALL 시점부터 timing score를 계산합니다.
